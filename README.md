# PI 3 — Biblioteca Digital Pública

Projeto base completo da Biblioteca Digital Pública, com foco em acessibilidade para pessoas com deficiência visual.

## Estrutura
- `backend/`: API Node.js + Express
- `frontend/`: interface React + Vite
- `database/`: schema SQL do PostgreSQL

## Observação
Antes de rodar o backend, configure `backend/.env` com os dados do seu PostgreSQL.
